# 10 real questions my user will ask

Write them the way your user would type them. At least 3 must need more than one page to answer, and at least 1 must be a question your documents cannot answer.

| **#** | **Question** | **Where the answer is (document, page)** | **Needs more than one page?** |
| ----- | ------------------------------------------------------------------------------------------------- | ---------------------------------------- | ----------------------------- |
| 1 | is my spring boot application affected by any critical vulnerabilities and which version should i upgrade to? | Relevant NVD CVE records and CERT-In advisories, pages to be identified | Yes |
| 2 | what is the latest CERT-In advisory for vulnerabilities affecting apache log4j? | Relevant CERT-In advisory and NVD CVE records, pages to be identified | No |
| 3 | explain the log4shell vulnerability, its impact, affected versions, exploitation risks, and recommended mitigation steps | Relevant NVD CVE records and CERT-In advisories, pages to be identified | Yes |
| 4 | which vulnerabilities affect the version of mysql used in my company and how severe are they? | Relevant NVD CVE records and CERT-In advisories, pages to be identified | Yes |
| 5 | what are the recommended fixes for critical vulnerabilities affecting our java dependencies? | Relevant NVD CVE records and CERT-In advisories, pages to be identified | Yes |
| 6 | what is the CVE ID and severity score for a known vulnerability affecting apache http server? | Relevant NVD CVE record, page to be identified | No |
| 7 | does CERT-In recommend any security actions for vulnerabilities affecting windows servers? | Relevant CERT-In advisories, pages to be identified | No |
| 8 | how can i check whether a particular software version is within the affected version range of a CVE? | Relevant NVD CVE records and vulnerability details, pages to be identified | No |
| 9 | which dependencies in my project's pom.xml have known security vulnerabilities, and what fixes are available? | Relevant NVD CVE records and CERT-In advisories, pages to be identified | Yes |
| 10 | what is the current salary of a cybersecurity analyst at a 40-person SaaS company in Guindy, Chennai? | None — salary information is not covered by the collected vulnerability documents | No |
